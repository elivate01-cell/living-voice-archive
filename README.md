# The Living Voice Archive

A catalogue-card oral history archive with typewriter metadata, language filter, contributing guide and reading-room information.

- **Category:** culture-community / oral-history-archive
- **Design family:** archival-catalogue
- **Pages:** index.html
- **Status:** local-draft (batch-3) — recommended tier: free-or-pro-review

## Run

```bash
npm install   # from the batch-3 root (npm workspaces) or inside this folder
npm run dev
npm run build # type-checks (tsc --noEmit) then builds to dist/
```

## Stack

React 18 + Vite 5 + TypeScript. All styling is hand-written CSS in `src/styles.css` — no UI libraries, no backend, no database, no routing library.

## Typography

Google Fonts (SIL Open Font License, served from fonts.googleapis.com): Courier Prime, Source Serif 4.

## Imagery

All visuals are original CSS compositions and inline SVG motifs drawn for this template (patterns, colour blocks, designed placeholder panels). No stock photography, no AI-generated people, and no external image URLs — nothing to break or mis-attribute.
